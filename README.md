# Batched LLM annotation dependence

Research workspace for an IEEE BigData 2026 study of whether annotating multiple texts in one LLM call creates dependence between item-level errors and changes uncertainty estimates.

The completed Gate A pilot supports continuing the idea. Step 1 of the budgeted study is complete, but its model and task screens narrowed the viable frozen confirmation to Qwen3-8B on Civil Comments. No Step 2 confirmatory output has been generated.

Start with [`HANDOFF.md`](HANDOFF.md), then read [`plan-120h-a100.md`](plan-120h-a100.md) and [`study-120h/STEP1_STATUS.md`](study-120h/STEP1_STATUS.md).

Large immutable protocols and raw outputs are stored as checksum-protected GitHub Release assets. See [`RESULTS_RELEASES.md`](RESULTS_RELEASES.md) for the publication boundary and archive contents.
