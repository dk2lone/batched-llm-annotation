# Four-family, four-task crossed replication plan

Decision recorded 2026-09-14 01:47:26 UTC, before any X1R4 joint output.
This CPU-only plan does not change the X1R4 seal, A7 admission lock, or
equal-family 1,000-evaluation priority. No new calls or budget are sealed here.

## Target and boundary

Run the **same four independent tasks** in Qwen, Granite, Llama, and Mistral:
16 fully crossed model-task cells. The target is to test whether excess
joint-minus-exact error covariance recurs across both selected tasks and model
families, with a family-by-task interaction analysis. This is a separate
replication. It does not retroactively expand the seven X1R4 admitted cells or
their Holm family.

The existing four tasks cannot supply the grid: only seven of the sixteen
cells passed A6, and no task passed in all four families. Preserve those
failures and do not relax a gate or replace a model after joint output.

## Required gates before paid crossed-panel work

1. Freeze an ordered registry of at most eight new candidate datasets, with
   up to two each for toxicity, sentiment, natural-language inference, and
   topic classification. Record revisions, splits,
   licenses, labels and reference provenance, task-specific prompts and solo
   capability floors, common response grammar, fresh disjoint frames, and new
   randomization namespaces. The registry must be fixed before any paid
   crossed-panel screen.
2. Solo-screen every registered candidate in all four fixed families under
   identical technical and admission rules. In each stratum, select the first
   candidate that passes in all four families using solo evidence only. Report
   every failure. If any stratum lacks an all-four-pass candidate, report the
   largest complete rectangle and state that the full 4 × 4 target failed.
3. Before any crossed-panel joint call, seal the sixteen selected cells,
   power-rule item counts, three randomized assignments per cell, joint,
   identical-neighbor exact-context, and solo call identities, worker owners,
   statistical tests, and a separate metered budget. Reforecast from measured
   runtime. No X1R4 ceiling is silently increased.

## Execution and claim

Use batch size 16 and the existing 2,048/4,096/8,192 power-rule ladder,
with fake-batch controls from independent labels. A sixteen-cell grid contains
137,216 to 548,864 B3 calls; all 4,096-item cells total 274,432 calls. These
are call counts, not an A100-hour quote.

The primary crossed estimand is the equal-weight mean of the sixteen cell
joint-minus-exact covariance contrasts. Report every cell, family and task
margins, their interaction, leave-one-family/task-out results, and frozen
malformed-output bounds. Seal the exact randomization test, multiplicity
family, and claim gate before crossed joint output. Claims concern the four
selected tasks and four pinned checkpoints, not all datasets or LLMs.

The X1R4 four-family 250-reference and 1,000-evaluation experiment retains
its four prespecified cells. The 4 × 4 grid tests dependence generalization;
it does not need 1,000 evaluation replicates in all sixteen cells. Paid
crossed-panel work follows the equal-family 1,000 target. The 2,500 prefix,
batch-size work, and extra checkpoint sizes remain later conditional work.

The X1R4 80-hour stop and 10-hour reserve stay fixed. A8–A12 is provisionally
40–61 guarded A100-hours before prior use and reserve, so this plan does **not**
establish that a complete 4 × 4 fits the current extension cap. A separate
budget seal or explicit pre-output budget amendment is required before any
paid crossed-panel work. The Freeze B 120-hour target is a different ledger.
