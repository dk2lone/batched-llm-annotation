# B5 flexible-analysis amendment

This amendment was made after Phase 1 model output completed but before any B5 effect estimate
was inspected. It does not change prompts, calls, assignments, estimands, thresholds,
resampling units, or the final equal-weight four-cell statistic.

The execution seal now covers data generation but not the analyzer implementation. The
analyzer accepts either complete two-model phase or all four cells and records that scope in
every result. A phase-only analysis is interim and cannot replace the final four-cell result.
